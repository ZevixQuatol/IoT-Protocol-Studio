## 已核对的行为

- 深色 / 浅色 / 跟随系统；系统主题改变时跟随更新，语言选择和显示偏好保存后重载可恢复。
- 字体大小、表格行高、HEX 字体、行号、毫秒时间显示；默认偏好不改变其他页面原有密度。
- 问题等级计数、等级 / 来源 / 搜索组合、无结果状态、上下文定位回调。
- 日志等级 / 来源 / 时间 / 搜索组合，结束秒包含 `.999`，无效时间范围阻止导出。
- 105 条记录分页：每页 50 条、末页边界、筛选后回到第一页。
- 当前筛选结果导出、复制选中日志、导出取消 / 失败提示、清空前确认、取消清空和清空后的空状态。
- 表格与详情选中状态随筛选 / 翻页保持有效；协议定位复用现有代码编辑器跳转和会话定位。

生产记录继续仅保留本次运行最近 500 条。旧记录只有 `problem` 标记时映射为 ERROR / INFO；WARN / DEBUG 仅在来源明确提供时显示，不生成虚构等级。敏感文本继续按 App 既有规则脱敏，截图中的示例只存在于开发 fixture。
