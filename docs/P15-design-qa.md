## 参考与实现

以用户提供的三张截图为视觉参考：1509 × 1042 的详情展开、详情收起，以及 1470 × 1070 的关闭会话确认。参考附件路径分别为 `codex-clipboard-967332be-0bec-4e30-a11e-f8daa1d4314c.png`、`codex-clipboard-12cb2e91-0dc4-47ff-b8f6-a397007e5e73.png`、`codex-clipboard-b63b424f-71ee-4234-a65c-c983ee9a7a97.png`。

- 复用现有 `TcpWorkspace` 的稳定 DOM 容器与 WebView2 分离 / 合并流程。新增 `SessionToolbar`，展示品牌、会话名称、合并、最小化、最大化 / 还原和关闭会话操作。原生窗口边缘缩放、工作区最大化和 DPI 消息保留。
- TCP 客户端独立窗口按顶部连接 / 协议配置、中部记录 / 详情、底部发送组织；通过独立样式限定范围，主窗口和其他通信页面保留现有布局。
- 收发记录显示实际方向、FRAME / SYS 类型、时间、消息、长度、HEX 和解析状态。筛选、记录文件、PCAP、时间线、关联与回放沿用现有能力；文件与自动跟随操作仍可从“筛选与文件工具”访问。
- 详情提供 HEX、字段与校验视图、字节范围高亮、在记录中定位，以及收起 / 展开侧栏。收起保留所选记录与发送草稿。字段 HEX 来自 Core 的 offset / length，遮蔽或截断字段不另行泄露 HEX。
- 紧凑发送区复用已保存模板、HEX / UTF-8、变量、有效值检查和现有单次 / 定时 / 批量发送；显示实际字节数。快捷键使用现有 Ctrl+Enter。
- `SessionCloseDialog` 使用应用内模态确认；取消保留会话，关闭期间防止重复操作，失败显示错误并保留弹窗。

## 与参考的明确差异

生产界面显示实际协议、地址、连接状态、发送队列和 Core 解码结果。没有将参考中的 18 bytes、CRC16 算法 / 数值、连接时长或任务数写入生产组件。字段表显示 Core 提供的值和类型，未编造独立十进制值或字段说明。自动重连继续使用已经实现的有限次数 / 间隔配置。

既有原生 `WM_CLOSE` / Alt+F4 行为是合并回主窗口并保留连接，本次继续保留。自定义标题栏 X 执行“关闭会话”确认；确认后使用既有 destroy 行为，清除当前会话队列、草稿和收发记录。参考中的“不会删除已记录的数据”因此改为准确提示：已保存的记录文件不受影响。已经发送的数据不会撤回。

## 验证边界
