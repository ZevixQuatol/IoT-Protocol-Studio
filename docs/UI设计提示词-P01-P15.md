# IoT Protocol Studio UI 设计提示词（P01–P15）

日期：2026-10-01。

以下 15 条为已组装好的独立提示词。每条都包含风格、布局和页面功能，复制对应整段即可使用，不需要再拼接总提示词。视觉参考为用户提供的深色交通管理界面图片。

## P01｜项目入口与项目管理

```text
为 Windows 桌面应用 IoT Protocol Studio 设计“P01 项目入口与项目管理”高保真 UI。

视觉参考：用户提供的深色交通管理界面图片。采用近黑石墨背景、低饱和灰绿、柔和圆角、细边界、轻微半透明面板、胶囊选中态、纤细线条图标和少量绿色强调。应用背景 #0B0E0D，面板 #151A17，浮层 #1C231F，主文字 #E8ECE9，次文字 #A6B2A9，主操作 #4DBF5C。面板圆角 12px，按钮与输入圆角 8px。中文正文 13–14px，路径和技术数据使用等宽字体。保持清楚的文字对比度。

画板为 1600×1000 正视桌面界面，完整展示应用。顶部为 Windows 自定义标题栏：绿色芯片图标、产品名、后退/前进、最小化、最大化、关闭。左侧 64px 主导航，顺序为协议工作区、调试、通信、环境与变量、设置，选中协议工作区。

生成两个独立状态画板：
1. 未打开项目：中央显示产品名称、简短用途说明、“新建项目”“打开项目”按钮和最近项目列表。最近项目展示名称、路径及打开、移除操作。整体安静、紧凑，避免大面积营销插画。
2. 已打开项目：左侧 260px 项目目录，中间显示当前项目的协议列表与快捷操作。使用 Smart Sensor Demo 项目，包含 protocols、examples 文件夹和 SensorLink 协议。目录可展开，选中协议有绿色弱强调。文件夹和协议通过行内更多菜单提供操作。

补充新建项目弹窗：项目名称、保存位置、选择目录、取消、创建。
补充目录菜单：新建文件夹、新建协议、重命名、移动、排序和删除。清楚区分显示名称与实际文件路径。

输出 P01-A 未打开项目、P01-B 已打开项目、P01-C 新建项目弹窗。所有状态共用同一组件和视觉规范。仅展示应用界面，无设备外框、手、透视、地图或交通内容。
```

## P02｜协议结构编辑

```text
为 Windows 桌面应用 IoT Protocol Studio 设计“P02 协议结构编辑”高保真 UI。

参考用户提供的深色交通管理界面：近黑石墨底色、低饱和灰绿、柔和圆角面板、细边界、局部半透明层次、胶囊标签、纤细图标和少量绿色强调。背景 #0B0E0D，面板 #151A17，浮层 #1C231F，文字 #E8ECE9 / #A6B2A9，主操作 #4DBF5C。面板圆角 12px，控件圆角 8px。中文正文 13–14px，字段、类型、偏移使用等宽字体。

1600×1000 正视桌面画板。顶部完整 Windows 自定义标题栏，使用绿色芯片图标。左侧 64px 导航：协议工作区、调试、通信、环境与变量、设置，选中协议工作区。

页面采用三栏：
左侧 260px 项目目录，打开 Smart Sensor Demo，选中 SensorLink。
中间为协议消息与字段结构，占主要面积。
右侧约 300px 属性面板。

顶部显示 SensorLink、保存状态和保存按钮，内部标签为“代码 / 结构 / 报文”，选中结构。

协议包含 ReadStatus 和 StatusReply。字段树展示 sequence、deviceId、temperature、flags、payloadLength、payload、crc。字段行显示名称、类型、长度或偏移，选中 temperature 后右侧展示字段名称、显示名称、类型、字节序和相关属性。

提供添加消息、添加字段、排序和删除操作。自动计算的信息使用清楚的只读样式。
复杂字段使用可展开结构，展示枚举、位域、嵌套结构、条件字段和动态数组的编辑方式。

输出主画板，以及 flags 位域编辑、条件字段编辑、动态数组编辑三个属性面板状态。每个状态为独立画板，保持相同布局。不要把所有复杂属性同时堆在主界面。技术内容清楚可读，禁止地图、设备摄影和装饰性假数据。
```

## P03｜协议 YAML 代码编辑

```text
为 Windows 桌面应用 IoT Protocol Studio 设计“P03 协议 YAML 代码编辑”高保真 UI。

采用参考图中的近黑石墨、低饱和灰绿、柔和圆角、细边界和轻微半透明面板。背景 #0B0E0D，面板 #151A17，浮层 #1C231F，主文字 #E8ECE9，次文字 #A6B2A9，主操作绿色 #4DBF5C，错误 #D77770。面板圆角 12px，控件圆角 8px。正文 13–14px，编辑器使用清楚的等宽字体和克制的语法高亮。

1600×1000 正视桌面界面。顶部完整 Windows 自定义标题栏与绿色芯片图标。左侧 64px 主导航：协议工作区、调试、通信、环境与变量、设置，选中协议工作区。

左侧 260px 显示 Smart Sensor Demo 项目目录，选中 SensorLink。
中央为大面积 YAML 编辑器，顶部包含协议名称、保存状态、校验和保存操作。
内部标签为“代码 / 结构 / 报文”，选中代码。

编辑器展示可读的协议 YAML，具有行号、缩进、当前行和错误行标识。示例包含消息名、字节序、字段类型和 CRC 配置；内容应符合协议定义，不用随机代码填充。

生成两个状态：
P03-A：协议已保存、校验通过。
P03-B：存在未保存修改及一个字段定义错误。错误行旁有标识，底部问题区展示错误原因、行号及跳转操作。给出具体修正方向，错误文本避免泛化。

编辑器承担主要面积，问题区可折叠。错误使用局部红色，不让整个页面变红。保持与结构页相同的项目目录、标题栏、标签尺寸和导航位置。仅输出平面应用 UI，无设备外框、透视、摄影背景或地图。
```

## P05｜HEX 报文调试与解析

```text
为 Windows 桌面应用 IoT Protocol Studio 设计“P05 HEX 报文调试与解析”高保真 UI。

采用参考图的深色石墨与灰绿视觉：背景 #0B0E0D，面板 #151A17，浮层 #1C231F，主文字 #E8ECE9，次文字 #A6B2A9，强调绿色 #4DBF5C。柔和 12px 面板圆角、8px 控件圆角、细边界、局部半透明、纤细线条图标。正文 13–14px，HEX 和数值使用清楚的等宽字体。

1600×1000 正视桌面画板。完整 Windows 自定义标题栏、绿色芯片品牌图标。左侧 64px 导航：协议工作区、调试、通信、环境与变量、设置，选中调试。独立调试可在未打开项目时使用。

主区域顶部为 HEX 输入框，提供粘贴、格式化、清空、选择协议和解析操作。
中央为主要字节网格：偏移、字节序号、HEX 与 ASCII，排列规整，便于连续选择。
右侧约 320px 为解析字段树，显示字段名称、类型、值和字节范围。

使用 SensorLink / StatusReply 示例。选中 temperature 字段，在字节网格中同步高亮对应范围；选中字节也能定位字段。显示 sequence、deviceId、flags、payload、crc 等字段。
校验结果以图标和文字显示“校验通过”或具体失败原因。

提供范围颜色标注、备注和标注导入导出。补充一个标注编辑小浮层。
下方或局部面板显示选中范围的 HEX、十进制和其他解释结果。

输出主页面、校验失败状态、范围标注状态。采用稀疏且一致的标注颜色，避免把网格变成彩虹。
无数据时提供清楚的输入引导。禁止地图、无关统计卡、设备摄影和透视外框。
```
