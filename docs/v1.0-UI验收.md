## 修正的主要不一致

1. P02 结构视图仍沿用旧布局，切换后项目目录消失，标题栏/导航尺寸改变。现在结构、代码、报文共用项目目录和主窗口框架，并更新结构摘要、字段行、属性面板与弹窗样式。小窗口将属性面板排在字段树下方，通过内部滚动访问。
2. 首页、通信、环境、设置存在多套主题变量。现在基础主题由 `styles.css` 统一定义，其他页面复用；连接/发送按钮、弹窗、结构选中态随主题一致变化。
3. 主窗口标题栏统一为 52px，主导航统一为 64px、48px 图标按钮；设置页恢复同一套图标导航。修正通信页高优先级 CSS 和活动按钮悬停导致的尺寸/状态偏差。
4. 修复窄窗口项目目录标题与工具按钮挤压；补齐键盘焦点、弹窗滚动和减少动态效果偏好。保留此前确认的 HEX 输入框无绿色焦点圈行为。
5. 修正中文界面的 `Schema`、`Message` 和消息选择提示；设置页主题预览图换成当前实际界面。Core、CMake、前端包与浏览器预览版本统一为 1.0.0。

共享规则位于 `apps/web-ui/src/ui-consistency.css`，由正式入口及相关独立预览入口最后加载。浏览器预览数据仅用于检查展示和交互，不进入正式应用。
