# P06 调试工具面板 — 2026-10-03

## 实现范围

P06 延用现有 P05 工作台。打开“调试工具”后，固定右侧面板展示工具导航及当前工具；保留 HEX 输入、16 列字节网格、字段解析和标注操作。中等窗口输入栏分行，窄窗口在工作区及工具面板内滚动。

- **P06-A 数值转换**：HEX / DEC / BIN 输入；8 / 16 / 32 / 64 位；大小端；大端与小端 HEX、有符号及无符号十进制、二进制，并按所选位宽展示 float32 / float64；逐项复制、整体复制、读取选区及 BCD / Unix 时间戳快捷入口。
- **P06-B 查找替换**：HEX / ASCII / UTF8 / BINARY / DECIMAL 输入；匹配表、数量、当前匹配、上一个 / 下一个、单次替换、全部替换及空替换删除。网格及字段选择联动；改变报文后清除旧解析结果和标注，需重新解析。
- **P06-C CRC / 校验**：全部报文或选区；含结束位置的起止偏移；按算法显示参数；CRC16/X25 预设；HEX、DEC、结果字节序列和复制。结果字节序可以切换而无需重新计算。仅在范围后有足够字节时比较这些实际字节，不将计算结果冒充协议校验结果。
- 保留字节反转、BCD、UTC 时间戳、位运算以及标注文件的现有 Core Bridge；所有转换、查找、替换和校验计算仍由 C++ Core 执行。

新组件 `apps/web-ui/src/DebugToolPanel.tsx` 管理工具状态；`DebugTools.tsx` 保留解析及字段选择。结果绑定生成它的输入 / 工具 / 项目上下文，切换配置立即隐藏旧结果，异步迟到结果不能覆盖新状态。
